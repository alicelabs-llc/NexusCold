# TechDigital public-source enrichment · AliceLabs LLC

## In the published browser workspace

Load a CSV, map company and website columns, accept the network notice and click
**Enriquecer lista**. Up to 10,000 selected rows are queried sequentially per run.
Wikidata returns candidate entities; GLEIF returns legal entities with LEIs.
Ambiguous identities need confirmation; supported unique exact organization matches may be attached automatically. A name alone is
not identity proof. Missing data is left empty. Provider failures remain visible.

For supplied or confirmed websites, Google Public DNS returns MX, SPF and DMARC
observations. A null MX explicitly means the domain declares no email; missing MX
is not proof of an invalid mailbox (SMTP may use an implicit A/AAAA fallback).
No SMTP check runs inside the browser. SPF/DMARC observations are not full audits.

Export contains every original row and column plus separate ENRICH_* columns:
observations, source URLs, timestamp, conflicts, errors and processing status.
Original contact values are never overwritten. Rows outside the run limit retain
not_processed. Clearing/loading/remapping cancels pending requests and results.
No contact patterns or employee counts are generated by an AI.

Queries disclose company names to Wikidata/GLEIF and domains to Google, plus
ordinary connection metadata. No full CSV is uploaded. No public proxy is used.
Provider access, CORS and quotas can change; a zero-cost source is not an SLA.

## Extract actual published website contacts

GitHub Pages cannot run Python or fetch arbitrary websites across browser CORS.
`enrichment_service.py` supplies the crawler separately. It is NOT deployed by
publishing the static website. Use an existing Python-capable server behind TLS.

```
python -m pip install aiohttp
# Set PROSPECT_SERVICE_TOKEN to a randomly generated 32+ character secret.
# Set PROSPECT_ALLOWED_ORIGIN=https://techdigital.site
python enrichment_service.py
```

Default bind is 127.0.0.1:8081. Proxy that port through your HTTPS server. A container
recipe is included at deploy/Dockerfile.enrichment; bind it to loopback on the host
and terminate TLS in the existing proxy. Keep the token in server secret settings,
never in a commit or public JavaScript. On the site open “Extracción de sitios web”,
enter your HTTPS service origin and token. They remain only in the current tab.

The endpoint POST /api/enrich accepts one website, a Bearer token and the configured
Origin. It returns published mailto/tel links, description and source URLs. It has:
actual public-IP DNS validation; no redirects; robots.txt checks (fail closed on
unavailable policy except 404); same-origin crawl; 5-page default (configurable up to 10) and 512 KB/page bounds;
35s job timeout; at most 2 concurrent jobs and 20 starts/minute per instance.
No access logs, contact cache or job database are enabled by this service. Hosting
providers may still collect infrastructure logs. Use per-user tokens/quotas and
persistent abuse controls before turning it into a multi-tenant public service.

A redirect is returned as site_http_301/302 rather than followed; supply the
confirmed canonical HTTPS website and retry. The crawler never bypasses a login,
CAPTCHA, robots exclusion or access block. No message is sent to any contact.

## Sources and realistic coverage

- Wikidata structured facts: https://www.wikidata.org/wiki/Wikidata:Data_access
  and https://www.wikidata.org/wiki/Wikidata:Licensing (CC0 structured facts).
- GLEIF legal identities: https://www.gleif.org/en/lei-data/gleif-api/ . Coverage
  is entities with a LEI, not every local business. Not a contact database.
- Google DNS JSON: https://developers.google.com/speed/public-dns/docs/doh/json .
- Company websites: actual public contact links only, subject to site policy.
- Hunter has API/free-plan access but requires an account/key and limited credits:
  https://help.hunter.io/en/articles/11060999-what-s-included-in-hunter-s-free-plan .
  It is not silently used with another user's key or described as unlimited.

This is file enrichment, not an Apollo-sized private contact database. Small
businesses absent from public registries need a supplied website plus the crawler
or a separately licensed discovery provider. SMTP validation remains available in
the desktop operator. Do not call missing contact data a verified lead.

## Bulk lists and downloads

The workspace accepts up to 10,000 CSV rows (2 MiB input). The run count follows the loaded list; set 100 for a demo.
Paste company names one per line if no CSV exists. Names are company names, not
an employee/person finder. Individual queries are paced and exact repeated
queries reuse session results. A 1,000-row input is not a promise of 1,000 found
contacts. Timing and coverage depend on provider limits and available sources.

Stop retains results; Continue skips completed rows and retries unfinished/error
rows. Export is always available for the current list, including unprocessed rows.
JSON exports include a resumable copy of input, mapping and observations; importing
one restores the job without storing a token. JSON/CSV/XLSX copies are plain files
containing your data, not encrypted backups. Provider candidate choices for
ambiguous pending rows are searched again when resuming a JSON checkpoint.

A unique normalized exact Wikidata label may be applied automatically only when
the entity has a supported organization classification and an observed website;
a supplied conflicting domain prevents automatic attachment. Ambiguous candidates
require confirmation. This is a matching heuristic, not certified company identity.

Download choices: formatted Excel XLSX, ordered CSV, TSV, JSON checkpoint and raw
CSV audit. Order can follow the input, company name or country plus company.
Excel has Contactos and Original sheets, readable widths, a colored frozen header,
alternating row fills and autofilters. All cells are explicit text to preserve IDs,
phone numbers and untrusted input without formula execution. CSV/TSV formula-like
values are escaped. Cells beyond Excel's 32,767-character limit require CSV/JSON.

## Broader discovery through a web search index

The authenticated service also supports POST /api/discover with company and city.
Set BRAVE_SEARCH_API_KEY in the server secret settings to activate it. The browser
never receives that key. With the service connected, rows without a website get
up to ten web-index candidates; the user confirms the relevant company website,
then the crawler extracts published contacts. The search index covers many sites,
but a bounded query does not visit every page on the internet or guarantee recall.

Brave requires an account and active plan. Its current pricing offers monthly
credits, not unlimited free searches. No account, plan or paid quota was activated
by this implementation. Configure an explicit provider spending limit before use.
Official documentation: https://api-dashboard.search.brave.com/documentation/pricing
and https://api-dashboard.search.brave.com/api-reference/web/search/get .
The crawler now defaults to five pages per confirmed site; PROSPECT_CRAWL_PAGES can
set 1–10 within the same per-request timeout and robots/rate constraints. It cannot
crawl millions of sites from GitHub Pages: a separately provisioned backend and
search account are still necessary. The capability is not marked hosted or live.

## Selectable public registries added after the public-apis review

The source panel adds ten public adapters: France Recherche d’Entreprises,
Norway Brønnøysund, Finland PRH/YTJ, ROR, Crossref, BrasilAPI CNPJ, FDIC, NYC
Socrata restaurant business data, UK FSA establishments and Pick an Agency.
Wikidata, GLEIF and Google DNS remain included. Source scopes and official docs
are published in sources.json and described in docs/PUBLIC-APIS-REVIEW.md.

Company-name lookups query those selected sources independently. A CNPJ lookup
requires a supplied CNPJ column; it does not discover CNPJs by guessing. Sources
return different fields: absence of a phone/email is not replaced by a generated
contact. Officer/partner details, births, inspection scores and regulator contact
information are not mapped into a company lead. Registry IDs remain separate
from generic websites and source_status records the selected queries per row.

All ten public adapters were checked against real JSON responses and CORS
headers. This is a point-in-time verification, not an availability promise or a
proof that every organization in a country is covered. The public-apis directory
contains useful candidates but is not a live service or a guarantee of free,
commercial, high-volume access. Optional server adapters (CMS NPI-2, SEC) remain
disabled without a configured service and token; no paid account was opened.

Each provider is paced, successful queries are cached for the job, schema errors
are not cached as no-match, and a 429 pauses that source. Paused rows remain
retryable on Continue. Changing sources or country scope requeues queries while
preserving existing observations. Country conflicts stop cross-country branch
merges and remain visible for review. Selecting a result never certifies legal
identity or outreach permission.

Pick an Agency is attributed with a profile link and CC BY 4.0 in the interface
and per-row source_status export. Source data rights remain independent of the
application's AL-1.0 license. For broad repeated OSM extraction, use a separately
provisioned instance or dataset, not unrestricted bulk requests to public servers.
