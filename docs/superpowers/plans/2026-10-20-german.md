# Germán Implementation Plan

> **For agentic workers:** Execute inline with superpowers:executing-plans; one independent whole-branch review at the end.

**Goal:** Operador local, chat opcional autohospedado y trabajos recuperables para NexusCold.
**Architecture:** Herramientas deterministas compartidas entre CLI y GUI, con modelo desacoplado. Proxy autenticado para inferencia propia.
**Tech Stack:** Python >=3.10, aiohttp, dnspython, cryptography, Tk; Docker Compose y Caddy para hosting.
**Spec:** `docs/superpowers/specs/2026-10-20-german-design.md`.

## Global Constraints
- Nunca ejecutar texto generado; consultas externas explícitas.
- Sin claves de proveedores para flujo local; remoto HTTPS con token.
- No afirmar entrega garantizada ni autenticación SPF/DKIM completa.
- No inventar infraestructura ni cambios DNS.

## Review Focus
- Celdas maliciosas e instrucciones en datos: sin efecto operativo.
- Reanudar con otro archivo/configuración: rechazar.
- DNS temporalmente inaccesible: desconocido, no ausente.
- LLM caído o respuesta excesiva: error acotado; conservar trabajo.
- Gateway: rechazar no autenticados y endpoints de administración.
