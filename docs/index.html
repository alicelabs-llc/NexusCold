Escritorio

Instala Python 3.10 o superior. Extrae el ZIP, instala las dependencias con python -m pip install -r requirements.txt y abre python ALICELABS_EXTRACTOR_GUI.py. En Windows también puedes utilizar TECHDIGITAL_PROSPECT.bat. La descarga es código fuente; no se incluye un ejecutable Windows validado.

Germán e IA local

El operador funciona sin IA. Para el chat instala Ollama desde su sitio oficial, descarga qwen3.5:4b y configura OLLAMA_NO_CLOUD=1 en el servidor. El endpoint local por defecto es http://127.0.0.1:11434. El modelo tiene licencia propia; RAM y velocidad dependen del equipo.

CLI y permisos

python prospect_cli.py review empresas.csv no realiza consultas de red. Los trabajos mx, smtp, enrich y enrich_smtp necesitan --allow-network. El gateway de chat autohospedado necesita HTTPS, token y consentimiento explícito remoto. No se publican credenciales en esta web.

Reanudar y proteger

Conserva el checkpoint .german y su archivo .key. Reanuda con --resume y la misma entrada, mapeo, modo y fuentes. La clave es necesaria para descifrar y cualquiera con ambos archivos puede hacerlo. Protege tus exportaciones CSV por separado.

Móviles y límites

El revisor web funciona en navegadores móviles modernos; acepta CSV UTF-8 de hasta 2 MiB y 10,000 filas. La aplicación Python es de escritorio. Revisión de sintaxis no significa buzón verificado; las señales SMTP tampoco garantizan entrega.
