Controles implementados

El revisor web analiza localmente, trata las celdas como texto y protege fórmulas al exportar CSV. La app valida destinos de red públicos para enriquecimiento, verifica TLS y acota conexiones y respuestas SMTP. Los trabajos nuevos guardan checkpoints Fernet autenticados por registro y verifican archivo/configuración al reanudar. El modelo asesor no ejecuta shell ni texto de los datos.

Claves y despliegue

La clave del checkpoint se guarda en un archivo separado; cualquiera con acceso a ambos puede descifrarlo. Protege permisos, copias de seguridad y cifrado del dispositivo. El gateway preparado utiliza token, límites de petición y concurrencia, modelo fijo y HTTPS con Caddy. Ollama queda sin puerto público en Compose. Cambia secretos, conserva TLS y valida el servidor real antes de atender usuarios.

Límites que debes conocer

CSV de entrada/salida no están cifrados por el checkpoint. El modo heredado puede mantener caché sin cifrar. El token del gateway es compartido: no hay autenticación multiempresa, cuotas por cliente ni certificación SOC 2 o ISO declarada. Las pruebas automatizadas no sustituyen una auditoría independiente de infraestructura o un benchmark real de entrega.

Reporte responsable

Comunica vulnerabilidades a legal@alicelabs.site con pasos reproducibles y el mínimo de datos necesario. No publiques secretos ni datos de terceros. Este canal no constituye una promesa de recompensa, plazo de resolución fijo ni exención para actividades no autorizadas.
