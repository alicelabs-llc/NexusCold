Datos y propósito legítimos

Utiliza archivos propios o datos que tengas autorización para tratar. La publicación de un contacto en internet no elimina sus derechos ni autoriza cualquier reutilización. Documenta la procedencia, el propósito y la base que correspondan a tu actividad.

Usos prohibidos

No uses el producto para phishing, suplantación, malware, fraude, acoso, doxxing, venta ilícita de datos o envío abusivo. No importes secretos de terceros, datos de menores ni categorías sensibles sin las garantías y autorizaciones exigidas. No eludas autenticación, CAPTCHAs, bloqueos, cuotas o condiciones de una fuente.

Comprobaciones y automatización

Limita concurrencia y volumen; no utilices DNS/SMTP para causar carga indebida o enumerar sistemáticamente buzones. Respeta respuestas de política, oposición y límites de los proveedores. El verificador no envía DATA. Si realizas campañas mediante otro producto, debes cumplir sus reglas, identificar correctamente al remitente y atender las bajas que correspondan.

Agentes e incidentes

Las automatizaciones operan bajo la autorización de quien las configura. No des a un modelo acceso a claves, shell o datos que no necesite. Reporta vulnerabilidades de forma privada a legal@alicelabs.site y evita acceder, copiar o divulgar datos ajenos para demostrar un fallo.
