GOOD QUESTIONS

Clear answers before you start.

Have a different use case? support@alicelabs.site

Is my CSV uploaded to a server?

Review processes the file in browser memory. Enrichment sends company names to Wikidata and GLEIF, and domains to Google Public DNS with permission; the full CSV is not uploaded. The desktop app queries web sources, DNS and SMTP when you choose those functions. See Privacy for each data flow.

Does valid syntax mean a verified email?

No. Syntax is a format check. The app can query MX and SMTP, but SMTP acceptance does not guarantee delivery. unknown and catch_all are inconclusive for an individual mailbox.

Is AI required?

No. Review, verification and job tools work without a model. Germán chat requires Ollama and downloaded weights, or a gateway configured on your own server.

Does it work on my phone?

The landing and local reviewer adapt to mobile screens and support CSV selection and export. The Python app is a desktop application; no native Android or iOS app is included.

Can I use the source free in my business?

The standard download permits non-commercial evaluation under AL-1.0. Commercial use requires written authorization from AliceLabs LLC. AI model licensing is separate from Prospect licensing.

What does agent-first mean here?

A documented CLI, llms.txt and a capability manifest support integration. Agents can use local tools with explicit permissions. The remote gateway provides advisory chat, not campaign execution or remote enrichment.
