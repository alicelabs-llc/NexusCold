Desktop

Install Python 3.10+. Extract the ZIP, run python -m pip install -r requirements.txt, then python ALICELABS_EXTRACTOR_GUI.py. Windows users can also use TECHDIGITAL_PROSPECT.bat. This is source code; no validated Windows executable is included.

Germán and local AI

The operator works without AI. For chat, install Ollama from its official site, download qwen3.5:4b and configure OLLAMA_NO_CLOUD=1 on the server. Default local endpoint: http://127.0.0.1:11434. Models have separate licenses; RAM and speed depend on hardware.

CLI and permissions

python prospect_cli.py review companies.csv does not query the network. Modes mx, smtp, enrich and enrich_smtp require --allow-network. Self-hosted chat needs HTTPS, a token and explicit remote permission. This website contains no credentials.

Resume and protect

Keep the .german checkpoint and its .key file. Resume with --resume and the same input, mapping, mode and sources. The key is required; anyone with both files can decrypt the checkpoint. Protect exported CSV files separately.

Mobile and limits

Browser review supports modern mobile browsers and UTF-8 CSV up to 2 MiB and 10,000 rows. The Python application is a desktop app. Syntax does not verify a mailbox, and SMTP signals do not guarantee delivery.
